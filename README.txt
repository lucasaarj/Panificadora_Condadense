# Panificadora Condadense — site inicial

Site institucional responsivo feito com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code (ou outra IDE).
3. Abra `index.html` no navegador. Para desenvolvimento, pode usar a extensão Live Server.

## Arquivos
- `index.html`: estrutura e conteúdo.
- `style.css`: identidade visual e responsividade.
- `script.js`: menu mobile, filtro do catálogo e link de WhatsApp.

## Personalizações importantes antes de publicar
1. Em `script.js`, substitua `5581999999999` pelo WhatsApp oficial (55 + DDD + número).
2. Confirme o endereço completo, horário de funcionamento e telefone.
3. Troque as fotos de demonstração pelas fotos reais da padaria e dos produtos.
4. Revise as categorias e descrições para refletir exatamente o que a panificadora vende.

As fotos atuais são imagens remotas de demonstração do Unsplash; precisam de internet para carregar.
O endereço e o horário exatos não foram presumidos. O botão de mapa abre uma busca pela Panificadora Condadense em Condado-PE.
