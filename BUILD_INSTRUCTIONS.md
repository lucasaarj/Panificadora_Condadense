# Build Instructions

## Vercel Web Analytics

This project now uses Vercel Web Analytics for tracking visitor data.

### Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Make changes to `src/script.js` (not the root `script.js`)

3. Build the project:
   ```bash
   npm run build
   ```

   Or use watch mode for development:
   ```bash
   npm run dev
   ```

### Deployment

1. Commit and push your changes
2. Vercel will automatically deploy
3. Enable Web Analytics in your Vercel project dashboard:
   - Go to your project settings
   - Navigate to "Analytics" tab
   - Enable "Web Analytics"

### Important Notes

- **Source Files**: Always edit `src/script.js`, not the root `script.js`
- **Build Output**: The root `script.js` is generated by esbuild
- **Analytics**: Will work automatically once enabled in Vercel dashboard
- **Lock Files**: Always commit `package-lock.json` after dependency changes

### Scripts

- `npm run build` - Build production bundle (minified)
- `npm run dev` - Watch mode for development
